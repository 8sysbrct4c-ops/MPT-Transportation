# Testing checklist

- [ ] Import both packs into Minecraft Bedrock.
- [ ] Confirm pack manifests load without errors.
- [ ] Spawn the bus in a test world.
- [ ] Confirm passenger seats and mounting/dismounting.
- [ ] Verify geometry, materials and textures.
- [ ] Test bus-stop placement and interaction.
- [ ] Test route and display updates.
- [ ] Test on the target Bedrock version 26.52.

Do not mark a build as compatible until it has been tested in-game.
