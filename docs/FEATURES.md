# Feature plan

## Bus displays
- Front, side and rear exterior LED displays: route number + destination.
- Interior passenger information display: route, destination, current/next/following stop, service messages and stop-request state.
- Display content should be configurable per route.

## Stops and stations
- Placeable named bus-stop blocks and station structures.
- Digital departure boards with route, destination, platform and estimated departure.
- Route stop lists and configurable dwell time.

## Vehicle behavior
- Passenger seating and safe boarding/alighting.
- Route-aware stop sequence.
- Stop request, arrival/departure announcements and door state.
- Optional manual driving and later AI/scheduled operation.

## Roadmap
1. Establish pack manifests and a working spawnable bus.
2. Add bus geometry, textures and display surfaces.
3. Implement route data and stop interaction.
4. Add station boards, announcements and door animations.
5. Test on Bedrock 26.52 across supported devices.
